# ARGUS artwork

`ArgusIcon.png` is original AI-generated artwork created for ARGUS on September
17, 2026: a green, many-eyed forest guardian on a dark rounded-square tile. It is
inspired by the requested fantasy personality, not an extracted game asset or
an official RLCraft/Lycanites logo. No affiliation is implied.

The source is a 1254 × 1254 RGBA PNG. `scripts/build-icon.sh` produces the standard
16–1024 pixel macOS representations and an ICNS resource using system tools.
The generated files live under ignored `build/`; no image-generation service
is a runtime or build dependency.
